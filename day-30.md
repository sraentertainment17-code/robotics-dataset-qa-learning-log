# Day 30: Next steps for learning

The 30 days covered the basics of checking robot datasets in the LeRobot format. Topics I want to keep practicing:

- Run `audit_checks_v1.py` on more public datasets and note where it breaks or gives false alarms.
- Watch more videos by hand. The tool cannot judge whether a camera is clear (#8) or whether a label is correct (#10).
- Try the "break it on purpose" test (Day 21) with other kinds of faults, such as a frozen camera picture.
- Improve the coverage rubric (Day 19) with more examples of narrow and broad datasets.
- Learn more about calibration files and what a dataset should carry (Day 18).
- Keep the notes simple: one question per check, and proof you can re-run.
